PULSE — локальный проект

Файлы:
- index.html — разметка приложения
- styles.css — оформление
- app.js — логика приложения

Запуск:
1. Распакуйте ZIP в отдельную папку.
2. Откройте index.html в современном браузере.
3. Для загрузки медиа и устойчивой работы IndexedDB рекомендуется запускать через локальный сервер (например, VS Code Live Server).

При первом запуске приложение открывается на пустом экране чатов. Демо-профили, сообщения, публикации, каналы, сообщества и видео не создаются автоматически. Разделы публикаций, видео, сообщества/каналов, сообщений, профиля и настроек сохранены.

Важно: это локальная версия. Доставка сообщений другим пользователям, онлайн-аккаунты и серверное хранение не подключены.
